# LAB 5 Product Preview

Flutter product preview application for a mobile development lab. The app shows a responsive product detail page with a hero gallery, product information, finish and storage choices, bookmark state, and an add-to-cart action.

## Project Structure

- `lib/main.dart` contains the product preview UI and interaction state.
- `test/widget_test.dart` verifies that the core product content renders.
- Platform folders are generated Flutter targets for Android, iOS, web, desktop, and tests.

## Run

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
